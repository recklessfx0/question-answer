# Governance
Founder approves charter, license and release policy. Maintainers approve architecture, protected merges and releases. Workstream leads own contracts and triage. Contributors and agents claim one approved task, use isolated branch/worktree, submit PR and evidence. Independent review required; security-sensitive changes require security review and human maintainer approval. No self-approval, production credentials or signing keys for implementation agents. Conflicts escalate to maintainer; document decisions in ADRs. Colnera coordinates assignments and dependencies; GitHub holds authoritative code, issues and reviews. Colnera-specific integration is not assumed or implemented.
