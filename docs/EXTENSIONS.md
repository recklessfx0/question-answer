# Extension contracts
Versioned manifest: ID, name, version, type, core/PHP compatibility, dependencies, entrypoint, license and declared capabilities. Extension types: plugins, themes, modules, widgets, providers, adapters, MCP tools, languages. Lifecycle discover → validate → stage → install/migrate → activate → disable/update/uninstall. Stable public hooks, events, service registration, routes, admin navigation, template slots, migrations and diagnostics. No core file edits. Signed packages, dependency checks, safe mode and recovery. PHP extensions execute with application privileges; capability declarations are informational unless enforced by specific APIs. Provide SDK, examples and contract tests. Marketplace deferred.
