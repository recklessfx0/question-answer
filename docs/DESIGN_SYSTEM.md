# Design system
Mobile-first app shell with bottom navigation, desktop sidebar, light/dark/system themes, CSS tokens, native HTML forms, accessible dialogs and bottom sheets, focus management, keyboard support, reduced motion, RTL, system fonts and self-hosted SVG. WCAG 2.2 AA target; manual checks in addition to automated tests. Server-render public pages with canonical URLs; JS progressively enhances navigation and composer. Nested question → answer → clarification → reply, with visible indentation capped at 2–3 levels and deeper threads expandable. Preserve stable permalinks and browser history. PWA manifest; optional public-only offline cache, never cache authenticated pages or secrets. Admin responsive with dashboard, content, moderation, users, permissions, themes, extensions, API/MCP, AI, performance, logs, backups, updates, localization, privacy and maintenance. Destructive actions require confirmation and authorization.
