# Security requirements
Target OWASP ASVS 5.0 L2, selected L3 controls for high-risk workflows; verify latest applicable standards before release. Threat model before implementation. Secure sessions, CSRF, contextual escaping, audited sanitization, PDO parameterization, resource-level authorization, rate limits, CSP, secure headers, upload validation and non-executable storage, SSRF defenses, password_hash with Argon2id where available, MFA, least privilege, privacy retention and export/deletion. API and MCP scopes never replace resource authorization. Untrusted AI output and tool content cannot authorize operations. Redact tokens, passwords and sensitive payloads from logs. No production secrets for agents.

Updates: signed metadata and artifacts, trusted keys and rotation, replay/downgrade protection, archive traversal and symlink checks, compatibility checks, staging, verified backups, maintenance lock, bounded resumable execution, journal, health checks and tested restoration. Database migrations may be irreversible; document recovery explicitly. Extension PHP is trusted executable code, not sandboxed by a manifest. Install requires privileged authorization and integrity verification. Secure defaults and negative tests mandatory.
