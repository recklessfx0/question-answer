# Project charter
Build a secure, fast, extensible, self-hosted Q&A CMS for humans and AI. Core must operate without external AI or infrastructure. Own framework, but reuse audited security primitives. Prefer small modular monolith, server-rendered HTML, native CSS and JS, progressive enhancement, and stable extension contracts. Keep public web root separate from private files; fail closed on unsafe hosts. Support multilingual content, accessible nested threads, editorial verification, citations, permissions, revisions and data export. Every change requires tests, docs, independent review and explicit acceptance evidence. Proposed license Apache-2.0; proposed databases MySQL 8.4 LTS and MariaDB 10.11 LTS, subject to compatibility testing. PHP 8.5 patch releases required. Decisions are provisional until approved in ADRs.
