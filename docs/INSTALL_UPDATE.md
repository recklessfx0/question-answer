# Installation and updates
Browser wizard: environment checks, private path checks, database connection, first admin, secure config, migration, installation lock, health report. Use an initial setup secret or equivalent ownership proof to prevent installer takeover. PHP 8.5, PDO MySQL, HTTPS, writable private storage, required extensions to be decided by feasibility tests. Proposed 128MB memory baseline; subdirectory and no-rewrite fallback; no SSH/Composer/Node required in production. ZIP built in CI. Optional CLI and cron. Admin updater checks signed release metadata, compatibility and disk space, creates verified backup, stages files, runs resumable migration with journal, validates health, recovers on failure. Manual upload fallback and documented recovery. Test fresh install, interrupted setup, upgrade, key rotation, unsafe archive and recovery on reference shared hosts.
